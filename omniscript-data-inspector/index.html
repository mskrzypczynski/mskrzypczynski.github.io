OmniScript Data Inspector

Live OmniScript data, structure and calls in a DevTools panel for Chrome, Edge and Firefox.

Chrome Web Store Source on GitHub

What it does

  • Data. What the script holds right now, as a tree, a form or raw text. A value that changes flashes amber. Filter by words, a path or key=value.
  • Structure. Every element joined to the live data, with its show rule, formula, Set Values and validation in plain words. It lists what may stop Next.
  • Calls. Every Data Mapper, Integration Procedure and Remote Action call, with input and output. A failed call is marked even when the response is HTTP 200.
  • Linked together. Jump from a value to its element and from a call to the element that made it. Open in Designer works for core and managed packages.
  • Mask values. Strings and numbers become placeholders in everything you copy, save or export.

Learn it

Start with Get started in five minutes, then the guides. The reference describes every control.

Privacy

Nothing is sent anywhere and the OmniScript is never changed. The panel stores only your settings, in the browser, on this computer. Read the privacy policy.
