OmniScript Data Inspector

Guides

One question at a time, with the exact controls to use. For everything else, see the reference.

Get started in five minutes

Open the panel, pick the script, turn Mask values on, learn what the three tabs are for and where the help is.

Why is this field hidden?

Find the rule that hides an element and see what the data holds now, condition by condition, in plain words.

Why can't I press Next?

List what may be stopping Next on the current step: empty required fields, firing Set Errors and validations, and custom components.

Why did this call fail, and what did it send?

Find a failed Data Mapper, Integration Procedure or Remote Action call, read the reason and see exactly what the script sent.

What changed in this step?

Watch the data change as you use the page, see what each call sent and returned during a step, and check what a Set Values computes.

Where did this value come from?

Go from a value in the data to the element that owns it, the Set Values that computes it and the calls that sent or returned it.

What the panel keeps on this computer

See what is stored in the browser, what stays in memory, and how to clear each part.

Report a problem

Turn Mask values on, copy the panel's short report, add what you did and what you saw, and fill in the issue form.
