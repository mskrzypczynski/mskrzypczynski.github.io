Why is this field hidden?

Find the rule that hides an element, see what the data holds now, and try other values without touching the page.

A field you expected is not on the screen. In OmniScript that usually means a show rule is false, or that the field sits inside something hidden. The Structure tab can tell you which, using the data the script holds right now, so you do not have to read the rule JSON.

Find the rule

  1. Open the Structure tab and pick your OmniScript in the top bar. Press Rescan if the list is empty.
  2. Type part of the field's name, type or label in the filter box. See Filter.
  3. Look for a dimmed row with a closed eye: it is not shown right now, and the status bar counts these ("2 hidden"). Leave Visible only (under Advanced) off, or hidden rows are not listed. See Hidden elements.
  4. Click the row. When a rule hides the element, the Visibility tab opens with the reason. On another detail tab, a red chip in the head brings you back to it.

If there is no Visibility tab, the element has no show rule the panel can see. Children of a hidden element are hidden too, so check the step or block above it.

Read the Visibility tab

The first line is one plain sentence, such as Hidden: Step:Plan is "Standard", not "Premium". Below it is the rule as a table:

  • ✓ true now and ✗ false now say whether the row is true, and ? can't tell means the panel cannot work it out (a formula or an operator it does not evaluate).
  • Field is what the rule reads. If the script has an element by that name, the name is a button that selects it.
  • Must be is what the rule wants, for example = "Premium".
  • Is now is what the data holds. It reads (empty) or (not in data) rather than staying blank.

A group reads ALL of these are true or ANY of these is true, with ✓ (holds now), ✗ (does not) or ? (can't tell) before it. The muted count after it, such as "1 of 2 is false", shows where you stand. More in the Visibility tab entry.

Try a different value

  1. Click an Is now cell, or press Enter on it.
  2. Type a value and press Enter. Escape drops it.
  3. The row, the roll-ups and the sentence at the top are recalculated, marked "edited" and "(what if)".
  4. Press Reset what-if to put every value back.

Nothing is written to the page. See What if.

Follow the field back

Turn Advanced on and the Visibility tab also lists Depends on, Used by and Written by (the Set Values elements that write into it). Each is a button that selects that element, so it is the quickest way to find what should have filled the field. See Depends on / Used by / Written by. Show in Data opens the Data tab at the element's value.

If Is now says (not in data), the data holds nothing at that key yet. A Data Mapper or Set Values element that should have written it has not run, or wrote it somewhere else.

When the panel is unsure

  • A ? means an unusual operator or a formula the panel cannot evaluate. It never guesses.
  • A ≈ marks a formula the panel worked out itself, and the sentence says "(estimated)". Treat it as a good hint, not a verdict. See Formulas.

The panel judges rules against the live data, not the bShow flag saved in the definition. If the two disagree, trust the Visibility tab.
