OmniScript Replay

Record the OmniScript steps you keep repeating and replay them the way a person would, in a Chrome DevTools panel. In development.

Source on GitHub Chrome Web Store listing coming soon.

What it does

  • Record. Go through the steps once and stop on the step you want to test. Values are read from the script's own data.
  • Replay. It fills each step, presses the buttons you pressed, waits for the page, presses Next and leaves you on the step under test.
  • Checks and results. Add checks to a step; each run ends as PASS, FAIL, STOPPED or ERROR, and the report can be saved as HTML.
  • Tests as files. Export and import recordings, and Replay all runs the list one after another.
  • Mask values. Strings and numbers become placeholders in exported recordings.

To look at a script's data, structure or calls instead, see OmniScript Data Inspector.

Privacy

Nothing is sent anywhere. The panel stores only your recordings and replay options, in the browser, on this computer. Read the privacy policy.
