Projects

OmniStudio Finder

On the Chrome Web Store
Chrome extension · toolbar popupGPL-3.0

Find OmniScripts, Integration Procedures, DataRaptors and FlexCards in your Salesforce org. See every version, open the right one.

  • Search as you type, or paste a Type_SubType_Language key straight from a log.
  • Every version as a chip, the active one in green; Enter opens it.
  • Opens the right designer for core OmniStudio or the Vlocity packages.

OmniScript Data Inspector

On the Chrome Web Store Free + Pro
Chrome extension · DevTools panelGPL-3.0

Live OmniScript data, structure and remote action calls, in a Chrome DevTools panel.

  • The live data JSON, with what changed highlighted as you click through.
  • Every element joined to its data, with visibility rules you can read.
  • Every remote action, errors flagged even inside an HTTP 200.

The core stays free. Some features will be part of a Pro plan.

OmniScript Replay

Experimental
Chrome extension · DevTools panelGPL-3.0

Record the OmniScript steps you keep repeating, then replay them the way a person would, and land on the step you are testing.

  • Real pointer and key events, one key at a time, waiting for each step to load.
  • Edit the test data in a form, add checks, and get PASS or FAIL per run.
  • Export tests as files to share them with your team.
